# Git Skills Showcase

A small portfolio project created to demonstrate my practical understanding of **Git and GitHub**.

## 📌 About the Project

This project is a simple website built with HTML, CSS and JavaScript.

The purpose of the project is to demonstrate how I use Git to:

- Track changes
- Create meaningful commits
- Create and manage branches
- Work on features separately
- Merge changes
- Connect a local repository to GitHub
- Push changes to a remote repository

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code

## 🌿 Git Workflow

I used a feature-branch workflow while developing this project.

```text
main
 │
 └── feature/gitSkills
       │
       ├── Make changes
       ├── Stage changes
       ├── Commit changes
       └── Push branch
              │
              ↓
           GitHub
              │
              ↓
        Merge into main
